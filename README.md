# 古法纸浆发酵批次追溯与处置系统

运行：

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-pulp-fermentation.json`，首次启动自动沿用并迁移旧记录。

## 功能

- **建档**：每批登记多份原料及占比，占比合计必须恰好 100%（缺失或超额均被拒绝）。
- **换缸与缸位时段**：保留每次入/换缸的起止时段；同缸在重叠时段被其他批次占用时阻止换缸。
- **每日观察**：温度、气味、纤维松散度、换水、霉点；出现霉点或酸败异味时，批次自动转入「异常观察」并生成带截止时限的待处置事项。
- **处置闭环**：必须填写处理说明并经复核（复核人 + 合格/不合格）；复核合格才关闭事项，不合格退回重处；全部事项关闭后状态恢复为「发酵中」。
- **状态闸门**：存在未关闭处置事项时，不能转为「可抄纸」。
- **时间线**：建档、原料、换缸、观察、处置、状态变化全部留痕，可按批次查看。
- **查询**：按批次编号、缸号、负责人、状态筛选；首页展示各状态数量与超期待办。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/batches?q=&vat=&owner=&status=` | 批次列表与筛选 |
| GET | `/api/summary` | 状态数量与超期待办 |
| POST | `/api/batches` | 建档（materials: [{name, ratio}]，合计 100） |
| POST | `/api/batches/:id/move` | 换缸（重叠占用会被拒绝） |
| POST | `/api/batches/:id/observations` | 每日观察（异常自动建事项） |
| POST | `/api/batches/:id/tasks/:tid/close` | 处置说明 + 复核关闭 |
| POST | `/api/batches/:id/status` | 状态变更（有未关闭事项不能转可抄纸） |
| GET | `/api/batches/:id/timeline` | 时间线 |
